ART STYLE BIBLE · VS2026 WHITE IDE PIXEL

围棋史莱姆 · 美术风格设定集VS2026 Modern White IDE · Programmer · Network Pixel Art

一句话定调：以 VS2026 的现代白色 IDE 为视觉基准：白色工作区、浅灰面板、Visual Studio 蓝为主色，搭配青紫品红高亮；棋子是程序员和网络工程师的荒诞科技物件，界面像一套会报错、会断网、会自动编译的 2D 像素开发工具。

核心风格 抽象搞笑 + 程序员梗 + 网络工程 + 复古像素禁止 3D、透视场景、写实材质、史莱姆主体基准 32×32 像素 / PPU 32

01视觉定位

世界观关键词

  • 程序员、服务器、路由器、交换机、打印机、软盘、U 盘、键盘、光标、终端、数据线。
  • 棋子不是传统骑士，而是“会走路的办公设备”和“有情绪的网络硬件”。
  • 所有严肃战斗都配一个荒诞细节：Boss 是暴走打印机，治疗是能量饮料雨，瞬移是加载圈。

参考图必须继承的特征

  • 纯 2D 正面 / 俯视，像游戏图标或 Sprite，不做 3D 场景。
  • 深蓝灰或蓝色像素描边，形体小而清楚，主体轮廓优先于细节。
  • 白色工作区、浅灰面板、Visual Studio 蓝色边框，青紫品红作为状态高亮，不使用黑色主题。
  • 表情直接画在设备屏幕或指示灯上，搞笑来自“设备一本正经地发疯”。
所有 AI 出图提示词末尾统一加：flat 2D pixel art, modern Visual Studio 2026 white IDE theme, deep navy pixel outline, white or very light grey background, Visual Studio blue with cyan violet magenta accents, no black theme, no 3D, no perspective, no gradients, no text, no slime。

02色彩与像素规范

#F5F7FB 工作区
#0078D4 VS 蓝
#B146C2 品红
#E5A900 黄
#16844A 绿
#D83B57 报错红
规范设定
像素单位原生绘制 32×32；放大只允许整数倍 2x / 3x / 4x，禁止平滑缩放。
轮廓深蓝灰或 Visual Studio 蓝色 1~2px 像素描边；小尺寸下轮廓不能断。
高光只用 1 个主高光色；高光是方块、横线或角点，不用软笔刷。
噪点允许 1~3 个故障像素、扫描线、断线；禁止满屏随机噪点。
背景默认纯白 / 浅灰平面，模拟 VS2026 工作区；概念图和 Sprite 不出现 3D 地面、透视房间、体积光。

05UI、卡牌与战斗界面

UI 形态

  • 手牌栏像电脑任务栏或文件夹，不像羊皮纸、木牌、石板。
  • 按钮像系统对话框：青色“准备”、品红色“重抽”、黄色“编译完成”。
  • 阶段指示使用 <PREPARE>、<RESOLVE>、<RESULT> 的代码标签感。
  • 错误和危险使用红色警告三角，不使用写实爆炸。

卡牌形态

  • 卡牌像软盘、终端窗口或设备驱动包。
  • 2×2 / 3×3 占格在卡牌右上角显示为荧光网格。
  • 稀有度用颜色，不用复杂边框：普通青、稀有品红、Boss 黄。
  • 文字只保留必要信息，图标先于文字。

08生产检查清单

检查项合格标准
是否纯 2D没有 3D 渲染、透视、体积场景或摄影式光照。
是否像程序员 / 网络工程至少包含终端、数据线、警告灯、光标、路由器、服务器、软盘之一。
是否搞笑有一个直观荒诞点，但不影响单位功能识别。
缩小后是否可读缩到 32×32 后仍能认出主体轮廓和阵营色。
是否能做 Sprite主体边缘干净、背景可抠、没有文字水印、锚点容易统一。
