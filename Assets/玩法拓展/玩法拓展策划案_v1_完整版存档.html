01现状诊断：为什么"有点单调"

先承认现有的底子是好的：它其实已经是一个"围棋 × 自走棋"的雏形，只是缺了构筑与随机性这两条腿。

四个"单调"的根因

根因表现本质
决策维度单一 每回合能做的只有"落哪个棋子、落在哪一格" 没有构筑（Build）：选择之间不产生组合效应，没有"1+1>2"的爽点
局内没有成长曲线 金币只用来落子，落完就结束；赢了直接进结算 没有滚雪球：玩家感受不到"我这局变强了"
每局都在重演 同一关卡的敌人阵容、落子节奏、胜负线完全一致 没有随机性：没有事件、没有遗物、没有"这局我抽到了什么"
对手没有性格 AI 走「选棋 → 落子 → 移动」的固定状态机，行为可预测 没有对抗叙事：玩家不会说"这个 AI 好阴"，只会说"它又这样落"

设计原则（贯穿全文）：不做"另一款自走棋"，也不做"更硬的围棋"。要把现有的气 / 被围这一条规则放大成战斗内核——让"站位"同时是自走棋的阵型与围棋的生死，这才是本作不可替代的地方。

02新定位与一句话卖点

《围棋史莱姆 · 弈境远征》——带一队史莱姆棋手，闯过一张随机棋局地图；每一格落子的位置，既是阵型，也是死活。

关键词在本作中的具体含义
肉鸽随机节点地图 + 遗物 + 事件残局 + 局内天赋，输了一局从头再来但带走局外成长
自走棋商店刷新 / 三合一升星 / 职业与种族羁绊 / 装备合成 / 站位策略
围棋气数可视化、气尽提子、双眼活棋、打劫、地盘计分、棋形加成
轻量单节点 2~3 分钟、单手可玩、失败可续命；不引入复杂的围棋收官与打劫规则细节

和竞品的差异：市面上的"围棋 + 自走棋"要么把围棋当皮（棋盘只是网格），要么把围棋当核（门槛劝退）。本作用一条折中线：围棋只保留气、提子、眼位、打劫、地盘五个最直觉的机制，其余留给自走棋的构筑深度。

03三层玩法循环

三层循环各自有独立的"爽点"，并且互不阻塞——P0 只做第二层就能显著改变观感。

① 秒级：战局循环
5~20 秒
落子 → 自动攻防 → 气数变化 → 提子。玩家看到的是"围"的血色脉冲与拔花特效。
② 分钟级：构筑循环
2~3 分钟 / 节点
打一个节点 → 拿金币与遗物 → 商店买棋 / 刷新 / 三合一 → 这一局的 Build 成形。
③ 局级：远征循环
30~45 分钟 / 局
3 章 × 5~8 节点 → 章节 Boss → 通关带走棋谱（局外解锁）与称号。

04肉鸽层：远征地图与节点

一局 = 3 章 × 5~8 节点，节点从下往上推进，每章末尾一个 Boss。地图随机生成但**同一种子的结果固定**（为每日棋局/回放打基础）。

节点类型表（数值为第 1 章基准，第 2/3 章按 ×1.6 / ×2.5 缩放）
节点出现率内容时长产出
普通战斗45%随机敌人阵容 + 随机盘面（星位盘 / 三三盘 / 空盘）2 分钟金币 5~8 · 经验 1
精英战斗12%带专属遗物的强化敌人（如"劫匪"）3 分钟遗物 1 · 金币 10

盘面变体（地图随机性的一大来源，成本极低）

已有 9×9 棋盘的四类改造

  • 星位盘：4 个星位格（天元、四星）落子攻速 +30%
  • 劫争盘：中央 3×3 为劫争区，区内被提子立刻返还 50% 金币
  • 封锁盘：随机 4~8 格不可落子（等于改变气路，围棋味极强）
  • 潮汐盘：每 30 秒边缘一圈格子沉没/回升

为什么值得做

盘面变体是"最低成本的高随机性"：不用新增美术、不用新增棋子，只改棋盘数据与判定，就能让每局的开局感完全不同，并且天然强化了"气 / 连通"这条围棋内核。

实现上只需给棋盘加一份"格子属性表"（可落 / 加成类型），现有 IsPositionValid 与棋盘索引直接扩展即可。

05自走棋层：商店 · 刷新 · 三合一 · 装备

这是把"落子"从一次性选择变成 Build 过程的关键一层，也是改造性价比最高的部分。

5.1 商店（把现有酒馆升级成每节点的商店）

机制规则设计意图
候选牌每次进店 5 张随机棋子（+1 张随章节提升），可锁牌制造"抽到什么"的随机爽点
刷新2 金币 / 次，每章首次免费；遗物可改价（如"众叛：免费但 +30% 售价"）金币的去处从"只落子"变成"落子 vs 刷新"的取舍
稀有度白 60% 蓝 30% 紫 8% 橙 2%（每章提升一档）与现有 4 职业 × 3 档美术天然对应
价格白 3 / 蓝 5 / 紫 8 / 橙 12 金币（对齐现有角色的 f_exp 成本）不新增经济概念，复用现有落子花费
手牌上限 8；上场上限 = 8 + 羁绊加成给"棋盘铺满 81 格"留空间，但不让开局就铺满

5.2 三合一升星（现有美术已完全就绪）

现有 65 个角色正好是 19 个系 × 3 个档位（例如 刺客1 / 刺客2 / 刺客3），美术、帧动画、底座与被围标识三档都已经画好。这意味着"三合一升星"不需要任何新美术：

合成结果属性倍率表现
3 × 同名 1 星1 个 2 星攻击 ×1.8 · 生命 ×2.0直接切到第 2 档立绘帧序列
3 × 同名 2 星1 个 3 星攻击 ×3.2 · 生命 ×3.6第 3 档立绘 + 底座光环 + 专属技能特效
3 星专属解锁该角色"棋灵技"—例：刺客 3 星 → 提子后瞬移到空位（复用移动力 f_move）

这张表把"升星"从数值系统变成可直接复用现有资源的表现系统——是全文里性价比最高的一条。

部位基础效果三合一产物

07围棋内核：气 · 提子 · 眼位 · 打劫 · 地盘

这是本作唯一的护城河。现有代码里已经有完整的"连通块 + 气"计算（被围判定），以下机制都是在它上面生长，而不是另起一套。

7.1 气数可视化（零门槛的"可读性"改造）

表现

  • 棋子脚下显示该连通块当前气数（小圆点 / 数字）
  • 气 = 1 时红色脉冲 + 心跳音效（"叫吃"预警）
  • 气 = 0 时被提子：拔花特效 + 棋盘格子留白 1 秒
  • 拥有双眼的连通块显示"活"字印（金色）

为什么先做这个

现在的"被围"是不可见的——玩家只能通过伤害数字反推。把它可视化之后，围棋规则从"隐藏机制"变成"可操作的战术信息"，同时为提子/眼位/打劫铺好了认知基础。

复用现有：ChessPieceMgr 里的连通块遍历与气计数；被围标识 围_0001 的帧动画可直接扩展成"气数指示器"。

7.2 提子（把"×4 伤害"升级成处决）

阶段规则说明
叫吃（气 = 1）受伤 ×2，红色预警给玩家一回合反应时间（留出救棋的操作空间）
提子（气 = 0）该连通块全部被提走（不再是 4 倍伤害）战斗高潮：一次提 3 子以上触发全屏特效与慢动作
棋魂每被提 1 子产出 1 点"棋魂"，可换遗物 / 装备 / 免费棋子把"被吃"从纯亏损变成资源，降低挫败感
反提被提位置相邻的敌人受到 50% 伤害（需遗物/羁绊解锁）给"诱敌深入"提供战术深度

7.3 眼位与活棋（最快让玩家"懂围棋"的一课）

  • 真眼判定：连通块拥有 2 个以上"真眼"（被自己完全围住的空点，且对方无法在眼内落子）→ 判定为活棋。
  • 活棋收益：免疫提子 + 全队攻速 +10%（可叠加 2 层）+ 金色"活"印。
  • 教学价值：玩家会在两三局内自发领悟"要做眼"——本作最优雅的规则教学，不需要任何文字教程。

7.4 打劫（Ko）：给战斗一个"高潮"结构

连续提子触发打劫：被提方在 2 回合内不能立即提回原位（打劫禁着），期间双方每回合获得 +1 行动力与 +3 金币，且打劫区高亮。

  • 作用一：制造"局势拉锯"的戏剧性节点，取代现在平铺直叙的攻防。
  • 作用二：给"劫材"这个概念一个游戏化出口——打劫期间每回合产出"遗物碎片"。
  • 作用三：AI 人格的差异化载体（"劫匪"人格会主动制造打劫）。

7.5 地盘计分与棋形加成

地盘计分（章节结算）

每章结束时按"围住的空点"计分：地盘多的一方获得章节奖励（金币 / 遗物 / 免费升星）。这让玩家在 Build 之外多了一条"围地"的胜利路线——和自走棋的"打爆对面"形成双胜利条件。

棋形加成（形合）

摆出经典棋形触发强力效果，棋盘越高亮提示：

  • 直三 / 弯三 → 该连通块攻速 +25%
  • 梅花五 → 连通块无敌 3 秒
  • 刀把五 → 被提时改为对敌方全体造成伤害

08遗物系统（50+，规则级改造）

肉鸽的灵魂：遗物不该只是"+10% 攻击"，而应该改写规则。以下 12 个示例覆盖四条轴：经济 / 战斗 / 围棋 / 流派。

遗物轴效果为什么有趣
棋魂灯经济我方每被提 1 子，永久 +2 金币/回合把"挨打"变成经济引擎，反向构筑
潮汐经济金币每满 10 的倍数，行动力 +1鼓励"屯钱"的另一种节奏
众叛经济刷新免费，但棋子售价 +30%明牌交换：赌运气还是赌钱包
屠龙战斗单次提子 ≥3 时，全队攻速 +40%（本局永久）与"提子"内核绑定，越滚越强
兵书战斗近战羁绊人数 +2让羁绊路径更早达成
观棋不语战斗前 10 秒不落子，获得 50% 护盾用"忍"换取节奏，反常规开局
鬼手围棋你的提子附带"反提"（相邻敌人受 50% 伤害）提子流的核心组件
天元尺围棋落子在天元格的棋子攻速 +50%、气 +1把"天元"变成必争之地
湿棋围棋敌人每次落子有 15% 概率失败（"棋子太滑"）幽默 + 直接的强度收益
劫材围棋打劫期间每回合获得 1 个遗物碎片（3 个换 1 遗物）把打劫变成刷资源的机会
兽印流派妖兽羁绊人数 +2，且提子也叠加攻击为妖兽流提供"质变"节点
阴阳流派一次性：与敌人整片阵型互换位置（解围/反包围）一盘棋级的战术翻盘

设计约束：任何遗物都不允许"纯数值 +20%"——每个遗物必须改写一条判定或规则，否则不进池。这条约束能让 50 个遗物各自有记忆点。

09局内天赋三选一

每通过一个节点获得 1 级（Lv1~12），每级三选一。天赋负责"小步快跑"的成长感，与遗物的"规则改写"分层。

进攻类

  • 近战攻速 +15%
  • 对"叫吃"目标伤害 +30%
  • 落子后该棋子首次攻击必定暴击

围棋类

  • 被围伤害倍率 ×4 → ×6
  • 每回合首个落子 +1 气
  • 提子后恢复 1 点行动力

经济类

  • 商店首次刷新免费
  • 每回合首次落子 -1 金
  • 节点结束额外 +2 金币

流派类

  • 指定 1 个羁绊 +1 人数
  • 本局手牌上限 +1
  • 开局多 1 个随机 2 星棋子

10AI 人格：把"一个状态机"变成 8 个对手

现有 AI 已经是状态机（选棋 → 落子 → 移动），扩展成"人格 = 权重表 + 行为脚本"的成本非常低，收益却是"每局对手都不一样"。

人格行为特征克制它的方式（玩家的解题点）
铁壁 围地优先进角守边、抢做双眼，很少主动进攻用提子流切开它的连通块
疯狗 抢气贴着你的棋子落子、疯狂叫吃它经济差，耐心换血即可
雷法 AOE极限堆法师羁绊，集中范围伤害分散站位、别抱团（与棋灵流互斥）
龟公 屯钱前 60 秒几乎不落子，之后一波铺满前期压血线，别给它翻盘窗口
劫匪 打劫主动制造打劫、反复争夺同一点做眼走活棋，让它无劫可打
兽群 铺场低费妖兽堆数量，靠妖兽羁绊滚攻击AOE / 提子清场
棋圣 Boss镜像你的构筑，但属性略高；每章学习你的习惯用没展示过的遗物组合打信息差
史莱姆之王 Boss分裂 + 复活，越拖越难杀；棋盘随回合变拥挤速攻提子，别让它铺满 81 格

实现路径：每个 AI 人格 = 一份「权重配置」（落子偏好、进攻/防守阈值、提子欲望）+ 可选的行为脚本。现有 SelectPieceState / MeleePlaceState / RangedPlaceState / MovePieceState 可以直接参数化复用。

15开发路线图 P0–P3

核心原则：P0 不新增任何美术，只用现有资源把"自走棋化"做出来，先验证观感是否质变，再决定后续投入。

P0 · 自走棋化（1~2 周 · 无新美术）

目标：同样的棋盘，观感完全不同
  • 羁绊系统（职业 4 轴 + 种族 4 轴，用现有两个字段）
  • 三合一升星（复用 3 档立绘）
  • 节点商店：5 张候选 + 刷新 2 金 + 锁牌（复用酒馆 UI）
  • 局内三选一天赋（12 级）
  • 气数可视化 + 叫吃预警

P1 · 肉鸽骨架（3~5 周）

目标：一局 30 分钟有起伏
  • 远征地图（3 章 × 5~8 节点，随机 + 固定种子）
  • 遗物系统（30 个，含 4 条轴）
  • 残局事件房（复用现有气判定，生成死活题）
  • 盘面变体（星位盘 / 封锁盘）
  • AI 人格 4 个（铁壁 / 疯狗 / 雷法 / 龟公）

P2 · 围棋内核 + Meta（6~10 周）

目标：做出护城河
  • 提子（处决）+ 棋魂资源 + 反提
  • 眼位与活棋判定
  • 打劫（Ko）机制
  • 地盘计分 + 棋形加成
  • 每日棋局（固定种子 + 最少花费榜）
  • 天梯异步 PvP（快照对战）
  • 师门 / 棋谱局外成长

P3 · 长线运营（持续）

目标：留存与传播
  • 赛季与排行榜、称号外观
  • Boss 人格 2 个（棋圣 / 史莱姆之王）
  • 更多棋盘尺寸与地形（11×11 远征）
  • 遗物池扩充到 80+、角色扩展到 8 职业
  • 回放与观战（棋盘快照序列）

16风险、取舍与验证指标

风险与对策

风险对策
围棋门槛太高只保留气 / 提子 / 眼位 / 打劫 / 地盘五条最直觉规则；用气数可视化与新手指引替代文字教程
改动一次太多严格按 P0→P1→P2 推进，P0 只用现有资源验证观感
单局太长节点 150~180 秒；允许中途存档退出；每章结束留"保存并离开"
数值膨胀建立"战力换算表"（1 星 = 1.0 单位），所有加成按单位换算，禁止线性叠乘
自走棋同质化所有羁绊/遗物必须与"气/提子/地盘"至少发生一次交互
随机性带来挫败保底机制：连败 2 次后商店必出 1 张紫卡；每章首次刷新免费

验证指标（P0 上线后观察）

指标目标
单节点平均时长120~180 秒
单局平均时长30~45 分钟
一局内"羁绊达成数"≥2 条（证明构筑成立）

17附录：术语与对标

术语表

气连通块相邻的空点数，为 0 即被提
叫吃气 = 1，处于被提边缘的状态
眼被己方完全围住的空点；两眼即活棋
打劫双方反复争夺同一提子点的规则
地盘己方围住的空点总数，用于章节计分
棋魂我方被提子产出的资源，可换遗物 / 装备
师门局外可选择的流派起点，影响初始棋子池

对标与差异

对标借鉴本作差异
杀戮尖塔节点地图、遗物、事件房战斗是棋盘自动战斗而非卡牌回合
云顶之弈商店刷新、三合一、羁绊羁绊之外还有"气/提子"的第二套生死规则
月圆之夜单局仪式感、轻量单手操作棋盘空间策略取代卡组构筑
围棋（死活题）气、眼、打劫把死活转化为实时战斗与构筑资源

一句话总结：现有工程已经具备了"棋盘 + 气 + 自动战斗 + 3 档棋子美术 + 双阵营 + 成就 + 广告 + 可用性能"的全部零件； 本方案不是重做，而是把自走棋的构筑骨架装进这副围棋骨架上，再用肉鸽的随机性驱动它反复重玩。
