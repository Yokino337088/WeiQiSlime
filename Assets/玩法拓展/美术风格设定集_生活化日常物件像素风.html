ART STYLE BIBLE · EVERYDAY PIXEL

围棋史莱姆 · 美术风格设定集日常物件拟人 · 轻松搞笑 · 一眼看懂

一句话定调：把扫帚、运动鞋、弹弓、茶壶、雨伞和闹钟变成会打架的小伙伴。小朋友不看说明也能凭外形猜出“谁跑得快、谁能保护、谁会远程攻击”；温暖的浅色棋盘和大图标让玩法先于世界观被看懂。

核心风格 生活化 + 夸张表情 + 轻松像素禁止 技术黑话作为主视觉、3D、透视场景、写实材质基准 32×32 像素 / PPU 32

01视觉定位

生活化原型

  • 玩家熟悉的家居、文具、玩具、食物和出行用品：扫帚、运动鞋、弹弓、茶壶、雨伞、闹钟。
  • 一个外形对应一个动作：鞋子跑得快、弹弓打得远、雨伞能保护、茶壶会照顾队友。
  • 敌人可以是捣乱的日常物件；Boss 用“大一圈 + 皇冠 + 显眼血条”，而不是靠专业名词区分。

读图原则

  • 纯 2D 正面 / 俯视，轮廓和动作优先，不做 3D 场景。
  • 暖棕色像素描边，奶油白底，蓝、橙、绿、红分别承担清晰的状态提示。
  • 每个棋子最多一个关键道具、一个夸张动作；不靠设备型号或文字解释职业。
  • 十秒测试：遮住名字，只看 32×32 缩略图，普通玩家应能猜对主要用途。
AI 出图统一补充：friendly everyday objects as cute characters, flat 2D pixel art, warm cream background, warm brown pixel outline, sky blue orange leaf green accents, exaggerated readable actions, no jargon, no computer UI, no 3D, no perspective, no text。

01.5历史标识：软盘图标（不作为新画风模板）

  • 原软盘图标文件保留，作为早期探索的记录；不再作为主视觉、角色或 UI 的出图基准。
  • 如需在旧版界面兼容展示，可保留原配色并限制在小角标；新入口改用“出发 / 图鉴”等直白图标。
  • 不继续制作同风格衍生图标，避免玩家误以为这是电脑知识题材。

02色彩与像素规范

#FFF8EA 奶油白
#5A4036 暖棕描边
#4D9FD4 天空蓝
#F39A43 活力橙
#62A96A 叶绿
#DE5C62 危险红
规范设定
像素单位原生绘制 32×32；放大只允许整数倍 2x / 3x / 4x，禁止平滑缩放。
轮廓暖棕色 1~2px 像素描边；小尺寸下轮廓不能断。
高光只用 1 个主高光色；高光是方块、横线或角点，不用软笔刷。
装饰最多一个夸张表情和一个职业道具；禁止满屏碎细节。
背景奶油白 / 淡木色平面；概念图和 Sprite 不出现 3D 地面、透视房间、体积光。

03角色与兵种设计

兵种视觉原型看图就懂的动作主色
近战 / 兵小扫帚向前挥扫，贴近敌人打活力橙
刺客 / 马跑鞋迈大步、留短短的脚印天空蓝
弓箭 / 车玩具弹弓拉开皮筋，隔远弹出小弹丸橙 + 蓝
法师 / 炮小茶壶隔着别的棋子喷出一串水花天空蓝
牧师 / 士象小雨伞撑开罩住同伴，表示保护 / 治疗叶绿
Boss / 将赖床大闹钟摇晃敲铃、戴皇冠，显眼又好笑危险红

升星保留同一物件的轮廓：1★ 小扫帚 → 2★ 带围裙的扫帚 → 3★ 2×2 大扫帚；不要换成另一个物件。此表是首批方向，其余角色也应优先从熟悉的生活用品扩展。

玩法状态像素表现玩家看到的含义

05UI、卡牌与战斗界面

UI 形态

  • 手牌栏像摊开的卡片盒；一眼看到“点卡片 → 点棋盘”。
  • 主要按钮只有“开始战斗”和“再抽一次”，大字、强对比、可点击区域宽。
  • 阶段用中文“摆棋子 → 看战斗 → 领奖励”和对应小图标，不用英文缩写。
  • 危险用红色感叹号 + 闹钟响铃，不靠技术警告框。

卡牌形态

  • 卡牌主体放大棋子头像与职业动作，不画硬件包装。
  • 2×2 / 3×3 占格用右上角方格轮廓表达。
  • 稀有度用蓝 / 橙 / 金表达，不能只靠颜色，旁边附星级。
  • 每张卡只保留角色名、星级与占格，不显示内部术语。

07AI 出图固定模板

正向提示词：

friendly casual game character based on one familiar everyday household object, clear action that shows its role, cute expressive face, flat front-facing 2D pixel art, warm cream background, warm brown outline, sky blue orange leaf green accents, crisp chunky pixels, single readable silhouette, ample space between characters

负向提示词：

computer interface, router, server, circuit, code, technical jargon, 3D render, realistic materials, perspective, isometric, cinematic lighting, detailed background, smooth gradient, text, logo, watermark, slime

AI 图仅用于方向探索；正式 Sprite 需重新绘制到原生 32×32 / 64×64 / 96×96，并保持序列帧同轮廓、同锚点。

08生产检查清单

检查项合格标准
是否纯 2D没有 3D 渲染、透视、体积场景或摄影式光照。
是否熟悉不读名字也能认出“扫帚 / 鞋子 / 雨伞”等物件。
动作是否直白至少能通过姿势猜到跑、打、保护或治疗中的一种。
缩小后是否可读缩到 32×32 后仍能认出主体轮廓和阵营色；至少邀请 3 位非游戏开发者盲测。
是否能做 Sprite正式资源需透明背景、干净边缘、统一锚点；概念图不能直接用。
